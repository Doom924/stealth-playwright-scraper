# Stealth Playwright Scraper — Парсер динамических JS-сайтов

Асинхронный парсер на базе **Playwright (Chromium)** для сбора данных с сайтов, использующих клиентский рендеринг (SPA / JavaScript), с оптимизацией трафика и выгрузкой в Excel.

## Ключевые особенности
- **Работа с JS-рендерингом:** полноценный headless-браузер с ожиданием сетевой активности (`networkidle`) и автоматическим переходом по пагинации.
- **Ускорение работы:** перехват сетевых запросов (`page.route`) с блокировкой загрузки изображений, медиафайлов и шрифтов.
- **Безопасность:** встроенная валидация URL и защита от SSRF (блокировка обращений к локальным и приватным сетям).
- **Экспорт:** автоматическая генерация отформатированной таблицы `.xlsx` (`openpyxl`).
